# Branding / naming notes

## What do we call it?

A few names stood out early: PW Play, FocusEd, Padhai Central. Problem
with all of them — they'd be a brand new name for a student to remember,
with zero inherited trust from the PW brand.

So the question became: why not name it something that's close to PW?

## Landing on "Pi"

Alakh sir (PW's founder) actually has a Pi (π) tattoo — that's where the
idea started pulling at us. Separately: Pi represents a circle, which
closely signals infinity. Any OTT-style platform needs to feel like it
has infinity content — you're never going to run out of things to watch
(or in this case, learn). That connection is what sealed it.

Decided to go with the name "Pi."
